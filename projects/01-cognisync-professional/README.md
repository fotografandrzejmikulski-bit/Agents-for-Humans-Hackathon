# Project 01 — CogniSync Professional

## Mission

A background-first professional agent that absorbs repetitive coordination work and surfaces only consequential decisions.

## Core loop

`observe → interpret → synthesize → prepare → evaluate consequence → act/wait → audit → learn`

## Key differentiators

- evidence-carrying insights;
- explicit consequence-aware policy;
- fail-closed unknown actions;
- human decision gate;
- append-only audit trail;
- optional MCP/A2A integration;
- local deterministic mode for reproducible evaluation.

## Prototype status

The main repository contains the executable local core, tests, evaluation matrix, architecture specification and grant proposal.

## Expansion plan

### MVP

Daily project brief, blocker detection, follow-up drafting, decision packets.

### V1

Real MCP connectors, durable memory, notification channel, trace correlation.

### V2

A2A specialist workers and adaptive model routing.

### V3

Professional vertical packs for creators, consultants and small teams.

## Source relationship

The project absorbs the background-agent thesis, evidence/provenance, autonomy boundaries and agent orchestration ideas already established in the repository. The present design is the implementation-oriented continuation of that work.
