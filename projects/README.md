# Projects

This directory is the project's portfolio layer: concepts extracted from the supplied source corpus are converted into concrete, testable implementation programs rather than remaining as notes.

## Project 01 — CogniSync Professional
Background-first professional agent with bounded autonomy, evidence/provenance, human decision gates, auditability, Strands/AgentCore compatibility and specialist A2A delegation.

**Status:** active prototype

## Project 02 — Sovereign Edge Agent
Local engineering agent architecture based on the supplied Gemma 3 27B / GGUF / hybrid CPU-GPU / MCP / Deep Search / NSVIF material. The implementation deliberately treats source performance figures as hypotheses to benchmark rather than guaranteed results.

**Status:** architecture + implementation plan

## Project 03 — Buildbox-Class Open Creator Layer
Engine-on-engine no-code creator platform over Unity/Unreal, centered on Mind Map navigation, typed visual logic, Smart Assets, event-driven runtime execution and automated build/monetization workflows.

**Status:** product architecture + MVP specification

## Project 04 — Influence Literacy & Ethical Communication Lab
A defensive/creative research system derived from the supplied influence, perception and persuasion material. It converts the corpus into a framework for analyzing persuasive design, detecting manipulative patterns, and producing transparent communication experiments. It intentionally excludes covert subliminal-control objectives and focuses on informed choice, disclosure and media literacy.

**Status:** research/product concept

## Project 05 — AI Content Product Studio
A productization system derived from the supplied content-prompt and side-hustle material: niche research, content packs, email sequences, blog systems and reusable digital products, with provenance, quality checks and human approval of publishing actions.

**Status:** product architecture
